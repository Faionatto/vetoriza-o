Busca linear : É o algoritmo mais simples para localizar
 um elemento em um elemento em uma lista ou vetor 

 OBS : Verifica elemento por elemento
 Funcionamento : Começa no primeiro indice e compara cada 
 item com o valor alvo


-----------------------------------------------------------------------------------------------------------

Busca binaria : É um algoritmo eficiente para econtrar um
 elemento em uma lista que obrigatoriamnete deve estar 
 ordenado

 Como Funciona : Ele vai dividindo a lista, dessa forma
 se torna mais rapida
